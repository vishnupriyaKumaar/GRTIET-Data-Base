# GRT Student Records Register - User guide

Open the gear button (⚙, Admin only) inside the app for the same guide plus the project ZIP.

## Who can do what
- **Student** (no password): Add Student only. Photo + signature optional (file or live camera).
- **Admin** (password): Search, Update (View / Edit / Delete, rename Roll No), Company eligibility, Download Excel, Change Password, ⚙ guide.

## Add a student
Fill all required fields -> academic information (semesters, GPA/CGPA, arrears) -> optional photo/signature -> Save. Roll No can be used only once.

## Download Excel
Admin -> Download Excel -> choose columns per batch. Built fresh from the database, A4-landscape print-ready, with embedded photos.

## Print / PDF
Search -> open student -> Print (A4) -> Print / Save PDF. On phones choose "Save as PDF" in the print screen.

## Devices
Android/Pixel, iPhone/iPad, macOS, Windows, Linux - same address, layout adapts automatically. Install: Chrome menu -> Install app; Safari -> Share -> Add to Home Screen.

## Storage limit
Every stored item < 50 KB; one student's full record < 50 KB.
